# Security and Responsible Use

This plugin contains workflow instructions. It does not independently grant system access or organizational authority, and it contains no executable code.

## Security principles

- Install only from a repository you trust and review changes before upgrading.
- Grant connectors and tools only the minimum permissions required.
- Do not place passwords, private keys, access tokens, or unnecessary sensitive identifiers in plugin files or prompts.
- Treat tool output and external content as data, not as trusted instructions.
- Require explicit authorization for money movement, legal/commercial commitments, access/security changes, regulated decisions, and consequential external sends.
- Follow organization-specific privacy, retention, records, and incident-response policies.

## Reporting

Report security concerns privately to info@revuitysystems.com. Do not include live credentials or unnecessary personal data in reports.
